# Triovexa v1.0.0-rc1

## Resulting behavior

This release candidate turns the original demo into a bounded incident-response system for Redis Streams worker stalls. A real Prometheus alert can now create an incident, produce a constrained restart recommendation, pass through an authenticated approval, restart the worker through the supervisor, and resolve only after telemetry confirms recovery in three consecutive samples.

## Included

- PostgreSQL workflow jobs with leases, retries, conditional transitions, and restart recovery.
- Atomic intake, approval, and execution claims with stable operation IDs.
- Session authentication, role checks, CSRF and origin validation, webhook credentials and rate limiting, approval expiry, evidence freshness checks, redaction, and a persisted kill switch.
- Heuristic, Mistral, and OpenAI-compatible reasoning paths with structured validation and recorded fallback.
- Redis Streams producer/worker/supervisor workload with bounded fault injection.
- Provisioned Prometheus rules, Alertmanager routing, Grafana dashboard and datasources, Loki, and Grafana Alloy log shipping.
- React operator console with incident, approval, connection, playground, and settings flows.
- Real PostgreSQL and Redis CI services, race checks, browser tests, accessibility checks, backup/restore verification, and the E2E-01 through E2E-07 runner.
- A fixed 30-case evaluation harness and reproducible heuristic baseline.

## Known limitations

- This is a release candidate for local and small internal staging deployments, not a claim of universal production readiness.
- The execution integration controls one allowlisted workload. Kubernetes, multi-cluster routing, arbitrary commands, and general autonomous remediation are outside this release.
- The application is single-tenant.
- Provider evaluation requires the operator's own credential and endpoint. No external-provider score is published without a real run.
- “OpenAI-compatible” APIs vary; the supported contract is Chat Completions with string message content and optional JSON response mode.
- The seven-day pilot and two unguided operator sessions are specified but still require elapsed time and human participants.
